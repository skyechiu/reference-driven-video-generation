# 附录：alche.studio 首页 Works 横向轮播拆解

> 采集日期：2026-09-26 · 视口 1440×900（DPR 1）· Chromium（SwiftShader 软件渲染）
> 方法：Playwright 驱动真浏览器看页面；注入"虚拟时钟"（接管 `requestAnimationFrame` / `performance.now` / `Date`，每步推进 1/30 s）逐帧推进和采样；读取线上 JS bundle 里的 shader 与参数；用 CDP 截帧测量像素。
> 只记录数字、参数和少量公式，没有保存对方的图片、模型或代码文件。按要求没有附截图和录屏。

**先纠正两个预期：**

1. **首页卡片里没有视频。** 6 张卡全部是 AVIF 静态图（WebGL 用 `-w1200`，1200×675，74–156 KB），DOM 里 0 个 `<video>`。
2. **上一份报告里"滚得越快图片横移越多"是错的。** shader 里确实有 `uScrollVelocity`，但顶点里乘了 `0.0`，片元里算出的 `moveUVOffset` 也没被用上。**实际没有速度相关的形变。**

---

## 0. 一句话结构

- DOM 里放 6 个 `100lvh` 高的空 `<div>`，它们只负责撑出滚动距离。
- 滚动进度 → 一个浮点"当前卡号" → 卡片摆在一条**斜向的圆弧**上（WebGL 平面，顶点弯曲）。
- 背后是一面**程序生成的半圆柱 LED 墙**，显示当前作品图的放大、饱和版。
- 文字是普通 DOM，按卡片切换做逐字进出。

## A. 轮播布局与运动

### A1. 一屏几张卡、各自多大（1440×900 实测 + 公式投影，两者吻合）

**全局参数：**
- 相机：`(0,0,10)` 看原点，`fov = 35 + 18/aspect`。1440×900 时为 **46.25°**。
- `spWeight = clamp((16/9 − aspect)/(16/9 − 9/16), 0, 1)`：1440×900 → 0.146；16:9 → 0；手机 → 1。
- 卡片组：`position.y = 0.8·spWeight`，`scale = 1 − 0.4·spWeight`（16:9 时为 1，手机为 0.6）。
- 卡片网格：7.95 × 4.47 × 0.195 单位（16:9），四边倒角约 0.05，4 段。

**每张卡的摆位**（`x = 卡序号 + 1 − 当前卡号`，即相对中间卡的偏移）：

```
pos.x = sin(x) * 11
pos.y = -x                   // 左上 → 右下的斜线：左邻高 1，右邻低 1
pos.z = cos(x) * 5 - 6
rot.y = x * 0.6              // 每格 34.4°，这是平面转角
scale = 0.9 + 0.1*spWeight + 0.2*(1 - min(1,|x|))    // 中间 1.1，|x|≥1 时 0.9
alpha = (1 - smoothstep(0.8, 2.5, |x|)) * min(1, u*2) * min(1, (N+1-u)*2)
```

**1440×900 下的屏幕占比：**

| x | 缩放 | alpha | 转角 | 屏幕包围盒 | 占宽 / 占高 |
|---|---|---|---|---|---|
| 0（中间） | 1.115 | 1.00 | 0° | x 316–1124，y 201–675 | **56% W / 53% H**（808×475 px） |
| ±0.5（切换中） | 1.015 | 1.00 | ±17.2° | 半张出屏 | 40.5% W / 48% H |
| ±1（左右邻） | 0.915 | 0.96 | ±34.4° | 右邻 x 1281–1533，y 346–710 | 屏内只露约 **160 px**；高 40.5% H；近边高 365 px，远边高 271 px |
| ±2 | 0.915 | 0.21 | ±68.8° | 基本出屏 | — |

**结论：** 一屏 = **1 张完整中间卡 + 左右各露出约 11% 屏宽的一条侧卡**。

**其它画幅：**
- 16:9（1920×1080）：中间卡占 54% W × 57% H。
- 手机（390×844）：中间卡占 78% W × 21% H。

**弯曲方式：两者都有。**
- **侧卡的斜度是平面转角**：`rot.y = 0.6·x`。
- **每张卡本身是网格弯曲**：顶点里 `z *= 0.2`（厚度压到 0.039），然后 `z += cos(x_local · π/8) · 1.5 − 1`。
  - 卡中心向镜头凸出 0.5，左右边缘只凸出 0.06，**差值 0.44 单位**（约为卡宽的 5.5%）。
  - 这是"外凸的桶形"：卡的上边中间拱起、下边中间下垂。
  - 左右边的斜率约 30°。
  - 注意：法线没有跟着弯曲更新。

### A2. 输入方式

| 输入 | 有没有 | 细节 |
|---|---|---|
| 滚轮 / 触控板 | ✅ 唯一主力 | Lenis 1.3.4 默认值：`lerp 0.1`、`wheelMultiplier 1`、`smoothWheel true` |
| 触屏 | ✅ | `syncTouch false`：原生滚动，没有 Lenis 平滑 |
| 键盘 / 滚动条 | ✅ | 原生滚动，同样会触发吸附 |
| 拖拽卡片 | ❌ | 没有拖拽逻辑 |
| 点击卡片 | ⚠️ | 射线检测，按下到抬起 < 300 ms 视为点击；**跳转作品详情页**，而不是把这张卡滚到中间。悬停时光标变 `pointer` |
| 左侧段落指示器 | ✅ | `lenis.scrollTo(target, {duration: 1.2, easing: 1.001 − 2^(−10t)})` |

### A3. 滚动值 → 卡片位置

**滚动区间：**
- works 段：scrollY **1900 → 7300**（6 × 900 px）。
- 每张卡的锚点：**1900 + 900·i**（i = 0…5）。

**进度 → 卡号：**
- 进度触发器 `works_progress`：从 `top bottom` 到 `bottom top`，对应 scrollY 1000 → 7300，共 6300 px。
- 换算公式：

```
o = damp(progress) * (N + 1)                          // N = 6，卡 i 居中时 o = i + 1
c = round(o)
u = damp(c - (c - o) * 0.4)                           // 显示用卡号：带"卡位"
```

- **卡位（detent）：** 偏离整数的量只保留 40%。结果是滚到两卡正中时，目标会从 `c + 0.2` **跳到** `c + 1 − 0.2`，再被平滑。
- 实拍帧里看得很清楚：前 0.6 s 中间卡几乎不动，然后"咔"地翻过去。

### A4. 缓动系数（全部是同一个 Lerper：`cur += (tgt − cur) · min(1, dt · 10 · mult)`）

| 量 | mult | 等效速率 | 60fps 每帧 |
|---|---|---|---|
| `works_progress` | 1 | 10 /s | 0.167 |
| `works_current_index`（卡位后） | 0.5 | 5 /s | 0.083 |
| `works_progress_velocity` | 0.5 | 5 /s | — |
| 背景墙 `bgQuadProgress` | 0.7 | 7 /s | 0.117 |
| 鼠标位置（流体用） | 1 | 10 /s | — |
| 相机跟鼠标 | — | `lerp(min(3·dt, 1))` | 0.05 |

**Lenis：** 每帧向目标靠近 10%（`lerp 0.1`）。

### A5. 停下后的对正（吸附）

**GSAP ScrollTrigger 设置：** `snap: { snapTo: 1/(N−1) = 0.2, duration: 1, directional: false }`，作用区间 1900–6400。

**内部规则（从 bundle 读出）：**
- 最后一次滚动 **0.1 s** 后检查。
- 只有速度 **< 10 px/s** 才吸附。
- 带惯性预测：目标 = `p + clamp(|v|/2 · v / 0.185)`，再取最近的吸附点。
- 缓动 `power3`（即 out）。

**实测（虚拟时钟 30fps）：**
- **一次 500 px 手势：**
  - Lenis 滑行 1900 → 2400 用时 1.3 s。
  - 约 1.43 s 开始吸附。
  - 约 2.3 s 精确停在 **2800**。
  - 全程约 **2.3 s**。
- **一次 200–400 px 手势：** 滑行后弹回 **1900**。
- **容差：** 最终落点像素级精确（`Math.round`）。视觉上的残差由卡位压缩，±0.5 卡 → ±0.2 卡。

### A6. 越远越暗 / 越小的曲线

**变小：** 只有两档。|x| 从 0 到 1 时，缩放从 1.1 线性降到 0.9；超过 1 之后不再变小。远处"显得小"主要靠 z 后退（z = −1 → −3.3 → −8.1）和转角。

**变暗：** 没有单独的亮度项，全靠 alpha。
- `alpha = 1 − smoothstep(0.8, 2.5, |x|)`。
- 卡片层清屏为透明黑，再用 `mix(bg, thumb.rgb, thumb.a)` 合成，相当于**乘了两次 alpha**，所以**实际亮度 ≈ alpha²**。

| \|x\| | 0.8 | 1.0 | 1.5 | 2.0 | 2.5 |
|---|---|---|---|---|---|
| alpha | 1.00 | 0.96 | 0.63 | 0.21 | 0 |
| ≈ 亮度 | 1.00 | 0.92 | 0.40 | 0.04 | 0 |

**两端淡出：** 第一张之前、最后一张之后，整组用 `min(1, u·2)` 和 `min(1, (N+1−u)·2)` 淡出。

### A7. 切换时中间卡内容和文字

**卡片内容：** 卡片本身**不做淡入淡出**，换卡就是卡片沿圆弧物理移动。只在贴图首次加载完成时，`uLoaded` 用 1 s 从 0 过渡到 1。

**背后的墙会切图：**
- 新旧两张图做一道**从左到右的软边擦除**，边宽为屏宽的 6%，进度 = 当前页的小数部分。
- 同时两张图横向平移 0.5 屏宽，形成视差。
- 每块格子还有一个随机的纵向 UV 偏移。

**信息文字：**
- **触发时机：** 第 i 个 900 px 空 div 的上下边越过屏幕中线时（`top center` / `bottom center`），也就是**滚过两卡正中那一刻**（例：scrollY 2350 切到第 2 张）。
- **进场：**
  - 容器：`opacity 0→1`，0.3 s，`power2.out`。
  - 标题（SplitText 逐字）：`y 10→0`、`opacity 0→1`，0.7 s，`power4`，stagger 0.01 s。
- **出场：**
  - 标题逐字：`y 0→−10`、`opacity →0`，0.4 s，`power2.in`，stagger 0.001 s。
  - 容器：0.5 s，`power2.inOut`。
- **实测：** 新文字在 t = 0.5 s 时 opacity 0.3，0.6 s 时 0.83；旧文字在 0.6–0.9 s 之间淡出，两者重叠约 0.3 s。
- **整块显隐：** 离开 works 段时 `.Works__container` 做 `opacity .5s ease`。

## B. 卡片材质（都在卡片自己的 ShaderMaterial 里，不是后期）

**关键事实：** 卡片单独渲到一张 RT，**在 Bloom 和流体扭曲之后才叠上去**。所以卡片不发光、不被鼠标扭曲，边缘干净锐利。

### B1. RGB 错位（色散）

**做法：** 片元里做 4 次采样取平均，每个通道用不同的镜头畸变系数：

```
cuv = (uv - .5) * 1.3;  cuv.x *= 0.9
lens(r, a) = r * (1 - a * dot(r, r))
a_R = 0.20 + fi*0.03,  a_G = 0.22 + fi*0.03,  a_B = 0.24 + fi*0.03     // fi = 0, .25, .5, .75
normalOffset 乘 1.00 / 1.01 / 1.02（R/G/B）
```

**范围：整张图都有，呈径向，中心为 0，越往四角越大。卡片外轮廓本身没有色边**（实测各通道在同一像素跳变）。

**实测偏移（中间卡 808 px 宽）：**
- 中心：0 px。
- 四边中点：R、B 相对 G 各 ±1 px。
- 离角约 100 px 处：±2 px（R 与 B 相距 4 px）。
- 公式推算最角落：R 与 B 相距约 10 px。

**透明度：** 100%，是替换采样，不是叠加一层。4 次采样的平均还会带来轻微的径向模糊（约 4–8 px）。

**附带效果：** 中心区域采样范围 ×1.17，边缘超出 0–1 的部分用 `MirroredRepeat` 镜像补齐。

### B2. 玻璃感

- **折射：没有。** 卡片不透明，不采样背景。
- **反射：没有真反射。** `uEnvMap` 声明了但没用。只有一道假高光：`mix(col, step-like(refDir.x), 0.05)`，即 5% 的明暗分界。
- **边缘亮线：没有独立描边。** "亮边"来自**倒角侧面**：
  - 侧面取 `uv.x = 1 − 0.19·normal.x`，把靠边的像素拉长贴上去。
  - 厚度 0.039 单位，在侧卡上约 **2–4 px**，颜色就是图边缘的颜色。
- **圆角：** 几何倒角约 0.05 单位，中间卡上约 5 px。
- **暗角：** `col *= smoothstep(0.9, 0.49, length(meshUV − .5))`。
  - 四角 ×0.45，四边中点 ×≈1。
  - 只压四角。
- **视差：** 转角后的卡，图像在框里会滑动：`uv −= normal.xy · 0.5 · smoothstep(0.8, 1, frontDir)`。|x| = 0.5 时约滑 13% 宽。

### B3. 中间卡"视频"

- **没有视频。**
- **图片：**
  - 卡片用 AVIF 1200×675（74–156 KB）。
  - 背景墙用同一张图的 800×450 版（47–88 KB）。
- **播放：** 所有卡同时显示，没有"只中间播放"的逻辑。
- **淡入：** 只有首次加载时 1 s。

## C. 背景与灯光

### C1. 暗格砖墙 = 程序生成的 LED 墙（不是贴图）

**几何：**
- `BoxGeometry(1, 1, .005, 4, 4, 1)` 做实例化，由四叉树生成。
- 规则：深度 > 3 停止；深度 > 2 时 50% 概率停止。所以格子只有 **1/8 和 1/16 墙宽**两种尺寸。
- 1440 px 屏幕正中对应约 **106 px 和 53 px**。
- 缝隙：`1 − 0.003·2^depth`，即 2.4% / 4.8%。
- 预生成 4 套随机布局；每 4 s 换一套（只在 KV 段）。

**透视：半圆柱内壁**（不是平面）。
- `θ = x·π`，所以横跨 180°。
- 半径 = 原点处可见宽度 / 2：1440×900 时为 **6.83 单位**。
- 高度 = 1.5 × 宽 = **20.5 单位**。
- 相机在 z = 10，从外面看进这片半圆柱内壁。

**内容（works 段）：**
- 当前作品 800 px 图 → 降采样到 256²（写了高斯模糊，但偏移 ×0，所以实际只是降采样）。
- HSV 饱和度 ×2。
- 10% 随机颗粒。
- **LED 圆点：** 每墙宽约 414 个；`dot = smoothstep(.5, .2, len(fract(uv·414) − .5))`；`col *= mix(dot, 1, .6) · 0.9`。
- **衰减：** 以墙中心为圆心 `smoothstep(.55, .05, dist)`；每块格子再加 `smoothstep(1.9, .1, …)` 格内暗角。
- **整体 ×0.5。**

**Bloom：** 阈值 **0.9**，3 级（1/4、1/8、1/16），每级 ×0.15·(0.5, 1, 1.5)，最后整体 ×1.3。所以墙基本不发光。

**实测亮度：** 墙区域 luma 中位数 **5/255**、均值 23；格缝接近纯黑。

**额外叠一层线格网：**
- 同一个半圆柱，64 × 64 格。
- 白色 alpha 0.1，线宽为格子的 8%（约 1 px）。
- 每 8 格一个十字，alpha 0.3。
- 在首页主场景里是静止的（`uScroll` 恒为 0）。

**随滚动怎么动：**
- 墙和网格本身**不转**。
- 进入 works 时，作品图从左往右铺上格子：`smoothstep(0, .3, −screenX + progress·6·1.6)`。
- 进度 0.9 → 1 时整体淡出。
- 每翻一页：图横移 0.5 屏宽，加上 A7 说的软边擦除。
- 格子另有随机"故障"：UV 错位和熄灭，按段落参数每 0.1–5 s 随机一次。

**墙前还有：** 半透明水晶 A，在 works 段自转，速度 0.5 rad/s，回正力 0.1。

### C2. 鼠标光晕 = Stable Fluids（没有 DOM 光标、没有单独的灯）

**模拟：** 256 × 160（按屏幕比例）。
- 压力迭代 4 次，curl 0.02。
- 速度衰减 **0.99/帧**：60fps 下半衰期约 1.15 s。

**笔刷：**
- 半径 = `0.01 + 0.1·min(0.5, 速度)`，以屏宽为单位，即 **14–86 px**。
- 力 = 指针速度 × 30，钳制在 ±2。
- 指针本身 10/s 跟随，速度 5/s 平滑。

**影响的对象：**
- 主场景亮度 `×(1 + 0.8·|v|)`。
- UV 扭曲：合成时 `0.01·v`，最终再 `0.001·v`。
- LED 格侧面发光 `0.8·|v|`。
- 网格线轻微偏色 `0.005·v`。
- **卡片完全不受影响。**
- **颜色：** 不加色，就是把原画面提亮。

**实测：** 快速划过后，路径两侧 luma 增加 +10 到 +16（暗格底色 7–12，局部约 ×2）；网格线出现可见的波纹；约 1.5 s 后看不出。

**鼠标还影响：**
1. **相机平移 ±0.5 单位**（鼠标 NDC × 0.5，3/s 跟随）：墙视差约 ±20 px，卡片约 ±4 px。
2. 水晶 A 的悬停旋转（works 段系数 0.2）。
3. 卡片悬停光标变 `pointer`，点击跳转详情页。

### C3. 整体亮度分布

**全帧（中间卡居中时）：**
- luma 均值 **50/255**，中位数 **17**。
- **53%** 像素 < 20，**5.4%** 像素 > 200。
- 卡片区均值 118；背景区中位数 5。

**和 activetheory 比：** activetheory 的 Bloom 阈值为 0，全画面都有辉光和体积光的雾感；alche 的阈值为 0.9，而且卡片画在 Bloom 之后，所以是**"纯黑场 + 一张锐利高亮的卡"，亮度几乎全压在中间 56% × 53% 的矩形里**。

## 照做清单（直接抄）

1. **滚动骨架：**
   - 6 个 `height: 100lvh` 的空 div 撑出 5400 px。
   - 用 Lenis（`lerp .1`）+ ScrollTrigger。
   - 进度区间取 `top bottom → bottom top`，`o = progress·(N+1)`。
   - 吸附：`snap {snapTo: 1/(N−1), duration: 1, ease: power3, delay: .1}`。
2. **卡位：**
   - `u = damp(c − (c−o)·0.4)`，c = round(o)，λ = 5/s。
   - progress 先用 λ = 10/s 平滑。
3. **摆位：**
   - `x = i + 1 − u`
   - `pos = (sin(x)·11, −x, cos(x)·5 − 6)`，`rotY = 0.6x`
   - `scale = 0.9 + 0.2·(1 − min(1,|x|))`
   - `alpha = 1 − smoothstep(.8, 2.5, |x|)`
   - 整组 16:9 时 scale 1，竖屏时 0.6 并上移 0.8。
4. **相机：**
   - `fov = 35 + 18/aspect`，位置 (0,0,10)，lookAt 原点。
   - 鼠标偏移 ±0.5，每帧 lerp `3·dt`。
5. **卡片网格：**
   - 7.95 × 4.47 × 0.195，倒角 0.05。
   - x 方向细分 ≥ 12 段。
   - 顶点：`z *= .2; z += cos(x·π/8)·1.5 − 1`。
6. **卡片片元：**
   - 4 次采样，R/G/B 畸变系数 .20/.22/.24（每次 +.03·fi），`cuv *= 1.3`，`cuv.x *= .9`，贴图 MirroredRepeat。
   - 暗角 `smoothstep(.9, .49, len)`。
   - 5% 假反射。
   - 侧面取 `uv.x = 1 − .19·nx`。
   - 图像视差 `−N.xy·.5·smoothstep(.8, 1, N·Z)`。
7. **合成顺序：** 场景 → Bloom（阈值 .9）→ 最终合成 → **最后**用 `mix(bg, card.rgb, card.a)` 叠卡片层。卡片不进 Bloom，也不进流体。
8. **背景墙：**
   - 四叉树实例（1/8、1/16 墙宽，缝隙 2.4 / 4.8%），卷成 180° 半圆柱。
   - 半径 = 可见宽 / 2，高 = 1.5 倍宽。
   - 内容：当前作品图（800 px → 256²），饱和度 ×2，LED 点 414/墙宽 `mix(dot, 1, .6)`，中心径向衰减，整体 ×0.5。
   - 换页：6% 软边从左到右擦除 + 横移 0.5 屏宽。
   - 叠一层 64×64 白线格网（alpha .1）+ 每 8 格十字（alpha .3）。
9. **鼠标：**
   - 256 宽的 Stable Fluids，笔刷 14–86 px，衰减 .99/帧。
   - 只作用于背景：亮度 `×(1 + .8|v|)`，UV `+ .01v`。
10. **文字：** 按第 D 节表格照搬。
    - 触发点在两卡正中（`top center`）。
    - 进场：容器 .3 s，逐字 .7 s power4 stagger .01。
    - 出场：逐字 .4 s power2.in，容器 .5 s。
11. **亮度目标：** 背景中位数 ≤ 5/255，全帧均值约 50，中间卡均值约 118；超过 50% 的像素 luma < 20。

## 测量限制

- **渲染环境：** 软件渲染，DPR 1。真机 DPR 最高 1.5，像素数值要 ×1.5。
- **虚拟时钟：** 按 30fps 步进。Lerper 和 Lenis 与帧率无关，但流体的衰减是按帧算的：60fps 下衰减约快一倍。
- **吸附起跳时间：** 受 GSAP 速度估计影响，在虚拟时钟下不稳定。以代码参数为准（0.1 s 延迟，1 s 时长）。
- **卡片投影尺寸：** 用 bundle 参数算出，并和截图比对过：中间卡边界误差 < 5 px。
