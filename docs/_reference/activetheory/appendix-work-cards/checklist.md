## A. 卡片文字

### A1. 贴图与版式（1024×1024 画布，按画布像素写）
- 画布映射：UI 着色器 `uv = scaleUV(vUv, (0.42, 1)); uv = scaleUV(uv, 1.15)`（scaleUV 是 `(uv-0.5)/s+0.5`）→ 画布宽 = **卡宽的 63.6%**，画布高 = **卡高的 116%**。纹素不是正方形：**竖向拉长 1.19 倍** **[源]**
- 边缘遮罩：`smoothstep(0.5, 0.4, |uv-0.5|)`（x、y 都乘）→ 画布最外 10% 渐隐 **[源]**
- 字体：**NB Architekt Std Regular**（带内线的几何镂空体），白色 `#ffffff` **[源]**
- 标题：居中，字号 = `0.9 × lerp(130 → 100, 标题长度 5 → 20 字符, clamp)` 画布 px；字距 **0.01 em**；行高 **1.1**；换行宽 **700 px**（= 卡宽 43.5%）**[源]**
- 客户名（仅在没有 logo 时显示）：24 px，字距 **0.1 em**，行高 1.8，逗号替换成 ` /` **[源]**
- Logo：400×200 图，缩放 **0.65**（260×130），水平居中，`y = 客户名.y − 105` **[源]**
- 正文 copy：`alpha = 0`，不显示（但它的高度仍参与居中计算）**[源]**
- 纵向排版：`y = 470 − ½标题高 − ½copy高 − ½客户名高`；客户名 y；`标题.y = y + 客户名高 + 40` **[源]**
- 屏幕实测（"20 YEARS / OF XBOX"，两行）**[测]**：
  - logo 中心：卡中心**上方 17.5% 卡高**；logo 高 **6.2% 卡高**、宽 **13.4% 卡宽**
  - 标题块中心：卡中心**下方 4.4% 卡高**；大写字高 **≈11.6% 卡高**（45 px / 389 px）；行距 ≈ 53 px（13.6% 卡高）
  - 标题块宽 **44.6% 卡宽**；logo 到标题块顶部 **5.7% 卡高**
  - 字形：单字 31 px 宽 × 45 px 高（宽高比 0.69）；字间空隙 **≈2 px（0.05 em）**；内线描边 **≈3 px**
- 文字比玻璃**浮出 0.1（边缘）～0.4（中央）** 世界单位：`pos.z += 0.1 + smoothstep(1,0,|u-0.5|)*0.3`（弧形拱起，形成视差）**[源]**
- 文字平面斜切：`pos.y -= (u-0.5)*0.42`，纹理反向补偿 `uv.y -= (uv.x-0.5)*0.15` → 屏幕上净倾斜 **≈ −2°**，与玻璃板的 `pos.y -= pos.x*0.08`（≈ −3°）同向 **[源][测]**

### A2. 亮度 / 颜色
- 写入方式：`gl_FragColor = tex * mix(0.65, 0.9, uHover)`，**加法混合**叠到玻璃上 **[源]**
- 染色：HSV 里 `h = h*0.1 + hue(uColor) − 0.25`，`s *= sat(uColor)`，只混 **5%** → 看起来基本还是白字 **[源]**
- 加法层本身的增量 **[测]**：均值 **RGB ≈ (103, 100, 100)**，p95 luma **165–170**
- 叠加后文字像素 **[测]**：luma 中位 **198**，最亮 10% ≈ **(248, 255, 254)** → 顶端被裁成白色；整体色 = 白 + 字底下玻璃的颜色（青色卡 ≈ (147, 199, 216)，红色卡 ≈ (209, 170, 181)）
- 字底下的玻璃 **[测]**：约 **(44, 100, 119)** / **(104, 65, 73)** —— 字比底子亮 **+100 左右 luma**
- 离相机距离淡出：`× crange(距离, 5, 6, 1, 0)`（距离从相机**组**算起）→ 正对卡 = 1，相邻卡 ≈ 0.02 **[源][测]**

### A3. RGB 错位 / "扫描线"
- 公式：`getRGB(tMap, uv, 180°, 0.001 − edges*0.15)`；R 取 uv+offset，B 取 uv−offset，水平方向 **[源]**
- `edges = smoothstep(0.9 + uHover, 7.0, |viewDir.x − 0.5|)`（viewDir 是视空间坐标，单位为世界单位）**[源]**
- 正对卡：offset **0.001 UV**（约 0.4 屏幕 px）→ 实测 **0 px** **[测]**
- 离轴 41°（滚到两卡中间时）：实测 R/B 各 **±2 px**，R↔B **5 px**（1280 宽）**[测]**
- 切片：`uv.x += fract(uv.x * 15) * edges` → 离轴时每个画布宽切成 **15 条竖切片**；`uv.y -= uv.y * viewDir.x * 0.15 * edges` 附带竖向错位 **[源]**
- **没有横向扫描线**：`fract(lineUV.y*7)` 那段扫描线代码在当前版本里是**注释掉的** **[源]**
- 整屏颗粒：GlobalComposite 里 `blendOverlay(color, noise, 0.15)` —— 这是全屏胶片噪点，不是卡片专属 **[源]**
- 视频/缩略图也有错位：`getRGB(…, 0°, 0.005 * edges)` **[源]**

### A4. 荧光感从哪来（按贡献排序）
1. **加法白字**叠在有色玻璃上（+100 luma），并且顶端被裁白 → 主因 **[测]**
2. **Bloom** 占**文字亮度的 14–17%**、**卡片亮度的 7–7.6%**、整帧的 1–2.5% **[测]**
   - `UnrealBloom "globalbloom"`：strength **0.3**，radius **0.2**，dpr **0.3**，阈值 **0**（跳过亮度提取，整帧都参与），3 级 mip，核 **3/5/7**，权重 **1/0.8/0.6**；合成时 `color += pow(bloom, 1.8)` **[源]**
3. 镜头光条 HydraLensStreak：阈值 1、强度 0.1 → 实测贡献 **≈0** **[测]**
4. **不走** emissive / 体积光 MRT：卡片的 MRT 只有 `Color` + `WorkRefraction`，文字着色器只写 `Color`；Work 场景没有体积光层 **[源]**

## B. 悬停

| 项 | 值 |
|---|---|
| 触发 | 射线命中玻璃板 mesh → `hovered = true` **[源]** |
| 过渡 | `uHover = lerp(target, uHover, 0.08)`，按 60 Hz 帧率归一化 → **指数缓动，τ = 0.20 s**：50% @ **0.14 s**，90% @ **0.46 s**，95% @ **0.60 s**，99% @ **0.92 s** **[源]** |
| 实测曲线 | 真实鼠标移入：0 → .632 → .865 → .950 → .982（每帧 Δt 被封顶 200 ms，每帧 α = 1−0.92¹² = 0.632，和公式完全吻合）；移出：1 → .368 → .135 → .050 → .018，**进出对称** **[测]** |
| 回落 | 和进入同一个 lerp，**没有单独的缓动/延迟** **[源][测]** |
| 位移 | 玻璃板和文字都 `z += 0.2 * uHover`（朝相机）→ 距离 5.79 → 5.59，**视觉放大 ≈ 3.6%**；**没有 scale、没有倾斜/旋转** **[源]** |
| 折射 | 法线偏移 `0.02 → 0.05`（**×2.5**）；折射采样缩放 `1/1.1 → 1/1.15`；折射亮度 **×0.7** **[源]** |
| 色光 | `blendAdd(uColor)` 权重 **0.3 → 0.5**，光斑中心从卡中心 **移到鼠标位置**（`mix(center, mouse, uHover)`），半径 `smoothstep(0.7, −0.1, d)` **[源]** |
| 边缘光 | `× (1 + vSide * uHover * 0.2)` → 侧面 **+20%** **[源]** |
| 中途闪光 | `× (1 + 0.3 * smoothstep(0.5, 0, |uHover − 0.5|))` → uHover=0.5 时 **+30%**，两端为 0 —— 进、出都会闪一下 **[源]** |
| 文字 | 增益 **0.65 → 0.9（+38%）**；切片起点 edges 0.9 → 1.9（离轴时少切一点）**[源]** |
| 实测卡面亮度（uHover 0 / .25 / .5 / .75 / 1）| 卡 A：**100 / 112 / 120 / 110 / 93 %**；卡 B：**100 / 108 / 115 / 99 / 88 %** → 先闪亮，最后比悬停前**略暗 7–12%**（折射 ×0.7），文字更亮 **[测]** |
| 光条 | 卡上没有悬停专属光条；常驻的是亮度波 `× (1 + 0.15 sin(2t + 5u))`：空间周期 1.26 个卡宽，时间周期 **3.14 s** **[源]** |
| 待机摆动 | `z += sin(0.5t + 3|0.5 − x|) * 0.1`（周期 **12.6 s**）**[源]** |
| 鼠标视差（常驻，与悬停无关）| `uMouse = lerp(Mouse.normal, 0.08)`；顶点 `x −= (mouse.x − 0.5) * 0.03`；折射 uv `+= (mouse − 0.5) * 0.02` **[源]** |
| 鼠标流体 | **卡片上没有额外加强**。流体（sim 256 / dye 512 / curl 30 / pressure 0.8 / velocity 0.98 / density 0.97 / 半径 5）只推动花形粒子；全屏合成里的流体扭曲都乘了 `uContact`，在 Work 页为 0 **[源]** |
| 视频 | 最近的那张卡播放共享视频：`uVideoBlend` **0 → 1，500 ms，easeOutSine，延迟 300 ms**；其他卡显示缩略图 **×0.7**，放大 1.1 倍，并带 0.05 的法线扭曲 **[源]** |

## C. 排列的空间感

### C1. 停在一张卡上（16:9，1280×720）**[测]**
| 卡 | 距相机 | 与视线夹角 | 屏幕宽 × 高 | 屏幕位置 | 可见面积 | 文字 | 亮度（无 UI，均值/p90）|
|---|---|---|---|---|---|---|---|
| 正对卡 | **5.79** | **0°** | **46.8% × 54.1%** | x 26.7–73.5%，y 23.0–77.1% | **25.3%** | 1.0 | 55–62 / 101–131 |
| 相邻 ±1 | **7.76**（**+34%**）| **72°** | **13% × 52%** 的竖条 | 左上 x 8–21%、y 2–54%；右下 x 79–92%、y 46–98% | 各 **≈6%** | **0.02–0.03（基本没字）** | 42–97（随缩略图变：相对正对卡 −30% ～ +55%）|
| ±2 | 11.0 | 120°（看到背面）| 14% × 39% | 被 ±1 挡住大半 | 各 ≈1% | 0 | 39–57 |
| 脊椎后面那几张 | 12.2–13.6 | 125–160°（背面，UV 镜像）| 16–20% × 27–45% | 被正对卡和脊椎挡住 | 各 0.5–4% | 0 | 31–75；视频亮度 ×0.2（`fadeVideo`：|Δy| > 3 时）|

- 一屏里有 **9–11 张**卡部分入镜；**1 张能读**，**2 张是侧面竖条**，其余是脊椎后面的背面。
- 屏幕上**不重叠**：正对卡和相邻卡之间横向留 **5.5% 屏宽**的空隙；只有脊椎后面的远卡会被正对卡**压住**。
- 所有玻璃板都是 **alpha = 1、正常混合、写深度**（不是真透明）。"透"是靠采样 `WorkRefraction` 快照。

### C2. 玻璃（抄这套着色）**[源]**
```
refrUV = screenUV − 0.05*N.xy − waterN.xy*(0.02 + 0.03*uHover + 0.005*sin(2t+5u))
refrUV = scaleUV(refrUV, 1.1 + 0.05*uHover) + (mouse−0.5)*0.02
refr   = pow(radialBlur(tRefraction, refrUV, 8 个方向 × 4 次采样, 半径 5/1024), 1.5)
base   = env*0.08 + min(video, 0.5)*0.45 + 0.01*(u+v);  侧面 base *= 1 + vSide³
col    = base + refr * mix(1.1, 0.3, smoothstep(0.65, 0, r)) * mix(1, 0.7, uHover)   // 边缘透、中心实
col    = softLight(col, video, smoothstep(0.7, 0, r))
col   *= 1 + 0.15*sin(2t + 5u)
col    = add(col, uColor, (0.3 + 0.2*uHover) * smoothstep(0.7, −0.1, |uv − mix(0.5, mouse, uHover)|))
col   *= 1 + 0.2*vSide*uHover + 0.3*smoothstep(0.5, 0, |uHover − 0.5|)
```
- 法线贴图：`waternormals.jpg`，平铺，`+ cnoise(uv + 0.06t) * 0.01` 缓慢流动；环境贴图 `env1.jpg`（equirect，×0.08）
- 视频 UV：30% 锁定到屏幕空间 —— `videoUV = mix(cardUV, scaleUV(screenUV, 0.6), 0.3)` → "窗口"视差
- 实测贡献 **[测]**：折射 ≈ 卡面亮度的 **6%**；缩略图 ≈ **37–43%**；剩下是 env、底色和色光

### C3. 前后穿插顺序 **[源][测]**
1. 不透明先画：**脊椎**（SpineShader）、**锁链**、**花形粒子**（点精灵，不透明，写深度）
2. 再画透明队列，**每帧按离相机距离从远到近排序**：每张卡玻璃 `renderOrder = i`，文字 `i + 1`
3. 结果就是按真实深度穿插：正对卡（5.8）挡住脊椎（≈9.6）；脊椎挡住远卡（11–13.6）；粒子绕着脊椎，会从卡片边缘前面飘过（滚到两卡中间时最明显）
4. 玻璃里"透"出来的是 `WorkRefraction` 缓冲（脊椎 + 锁链 + 粒子 + 卡片背面），偏移并模糊之后看到的

### C4. 滚动 **[源][测]**
- Work 段高度 = **10 × 105 vh**；`progress = (scroll + H − start) / (11.5 H)`
- 卡位置 = `smoothStep(0.06, 0.94, progress) * (N − 1)`；相机目标在相邻两个目标点之间**直线插值（走弦，不走弧）** + 四元数 slerp
- 中段每张卡 ≈ **0.52 屏高**的滚动量（两头：0.79 → 2.4 屏高）
- 平滑：页面滚动 `lerp 0.1`（τ **158 ms**）；相机跟随 `lerp 0.2`（τ **75 ms**）；滚轮在 Chrome 上 `deltaY × 0.25`（Win）/ `× 0.33`（mac），再 `× 0.7`
- 两卡之间（f = 0.5）：两张卡各 **39.5% 屏宽**，都和视线成 **41°**，距离都是 **5.69**，横向间隙 **8.6% 屏宽**（脊椎和粒子露出来），相机离轴半径从 7.6 降到 **6.89**（走弦导致更靠近中轴）
- f = 0.25：当前卡 48% 宽、20°；下一张 25% 宽、59°
- 文字交接：`crange(距离, 5, 6)` → 离开的卡在 f ≤ 0.9 时文字都还在；进来的卡 f ≥ 0.2 就完全亮 → **f 在 0.2–0.8 之间两张卡同时有字**（离轴那张带切片和 RGB 错位）
- **没有吸附**：代码里没有 snap/磁吸，滚动停在哪相机就停在哪。"当前卡"（播视频的那张）= 离相机最近的，在 **f = 0.5** 切换。实用容差：|f| ≤ 0.06（≈ 0.03 屏高 ≈ 22 px 滚动量 @720p）时夹角 ≤ 5°
- 入场：每张卡 scale 0 → 1，**1200 ms easeOutQuint**，依次延迟 **200 ms × i + 200 ms**；出场 **400 ms easeInQuart**
- 手机竖屏：角度步长 35°，y 步长 0.16 × N，玻璃 scale (2.9, 2.7)，FOV 55
