LoRA experiment — Olivia Face LoRA (ComfyUI)
=============================================

Date archived: 2026-08-05
Status: display-layer dashboard evidence only — not a dissertation claim of
production-ready identity control.

Dataset
-------
- 64 raw portrait images generated by the author using ChatGPT image
  generation, saved to 01_Raw/.
- 40 of these were manually curated/selected for LoRA training, saved to
  02_Selected/ (mapping.csv in 01_Raw/ records the raw->selected relation).
- dataset_sample/ in this folder holds all 40 images from 02_Selected
  (olivia_001.png .. olivia_040.png), renamed dataset_001.png..040.png.
  Per the author's explicit request (5 Aug 2026), the full curated
  training set is shown on the dashboard as small thumbnails, not a
  6-image sample.

Training
--------
- Backend: ComfyUI (local), face LoRA trained on the 40-image selected set
  above.
- No formal step/epoch/rank sweep log was kept for this experiment; training
  hyperparameters are not claimed here beyond "trained in ComfyUI on the
  Olivia dataset" because they are not independently traceable to a log
  file. Do not add specific step counts, LR, or rank values to the
  dashboard/paper unless a training log surfaces to confirm them.

Generated output (evidence used on the dashboard)
---------------------------------------------------
- generated/lora_gen_163.jpg, lora_gen_180.jpg, lora_gen_181.jpg,
  lora_gen_194.jpg — 4 sample outputs from running the trained LoRA in
  ComfyUI, copied from "生成的图/163_副本.jpg" etc. in the source LoRA
  working folder. Confirmed by the author (5 Aug 2026) to be actual LoRA
  inference output, not additional ChatGPT dataset copies.
- This is a small, author-selected sample (4 images), not an exhaustive orx
  systematically-sampled output set. The dashboard page must say so and must
  not claim a measured stability/consistency metric (no ArcFace or other
  score was computed across LoRA outputs) — the "less stable than ChatGPT"
  claim is a qualitative, human-observed comparison only.

Claim boundary
---------------
- Do NOT claim: quantitative identity-consistency score for the LoRA output,
  a completed/production-ready LoRA pipeline, or that this LoRA was used
  anywhere in the Mode A/B/C evidence chain. This experiment is independent
  of the main reference-driven pipeline.
- Framing to use: an author-run side experiment testing whether a locally
  trained ComfyUI LoRA can reproduce a ChatGPT-generated synthetic identity;
  qualitative human review found the LoRA's own generations less consistent
  (face shape/lighting/likeness drift across samples) than the ChatGPT
  dataset it was trained on.

Included in dissertation: no (dashboard-only display evidence per user
request, 5 Aug 2026).
